# SOC Home Lab Project

This project documents my hands-on learning journey into cybersecurity by building a home Security Operations Center (SOC) lab. The goal is to simulate real-world attack and detection scenarios using a small virtualized environment, focusing on detection engineering, threat hunting, and adversary emulation.

## Lab Sections

#### Part 1 - Set up a small virtualization environment
#### Part 2 - Simulate and observe adversary behavior
#### Part 3 - Emulating adversary techniques for detections
#### Part 4 - Blocking an attack
#### Part 5 - Tuning false positives
#### Part 6 - YARA detection and automation

## Screenshots

All steps were documented with screenshots to provide visual context.

## What I Learned

- Virtual lab configuration for cyber defense testing
- Hands-on experience with C2 frameworks and endpoint detection
- Real-world attack simulation and detection response
- YARA rule writing and automation
- Importance of tuning detection rules for operational efficiency
